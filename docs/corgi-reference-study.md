# 高清柯基素材与呈现方式

记录日期：2026-11-21。

用户在查看程序生成的柯基后，指出毛发与材质缺少参考图中的质感，并明确选择“毛发质感优先，可改成预渲染动画”。本轮据此将柯基改为高清立绘的局部 2.5D 骨骼动画。西高地保留原来的实时 3D 模型和外观。

## 当前使用的素材

高清柯基直接使用用户提供的 1920 × 1920 透明 PNG，保存在 `assets/corgi-hd.png` 并嵌入程序。画面中的细密毛发、眼鼻材质、光影和角色造型来自该原图，不是本项目新制作的模型、毛发模拟或新生成的动画帧。

原图对应 nWave 官方《The Queen's Corgi》的 Rex 角色形象。此前的程序生成方案只把它作为造型参考；当前方案在用户提供图片并选择质感优先后，实际将这张立绘用作本地桌宠素材。

## 动画实现与当前边界

`CorgiSprite.cs` 将高清透明立绘贴到可局部变形的网格上，用轻量骨骼控制呼吸、头部轻蹭与点头、耳尾小动，并处理眨眼及坐姿打盹。喂食和玩球使用与立绘位置配合的饼干、网球道具。透明命中依据原图的 alpha，避免整个图片矩形拦截桌面点击。

当前只有一个完整坐姿视角。朝向变化通过镜像实现，不是真正的全角度转身；轻微局部骨骼变形也不等于重新渲染了完整动作。高清柯基暂不支持四足步行、自由散步或趴睡，睡眠保持坐姿低头闭眼。界面会说明这些边界并停用相关散步操作，西高地原有的散步设置和动作保留。

这次交付不把单张图包装成完整 3D 模型，也不声称已经拥有新生成的整套连续预渲染帧。后续如补充一致的多视角、步行和趴睡素材，再扩展相应动作。

## 检查重点

- 在实际桌面尺寸下检查原图毛发和眼鼻细节是否清晰，耳尖、尾部和脚底是否完整，透明边缘是否干净。
- 检查呼吸与头部动作是否克制，避免拉伸毛发或让脚底离地；闭眼覆盖不能留下明显虹膜或高光。
- 检查饼干和网球位置、朝向镜像及桌面点击区域，不以单独展示的原图代替程序实际画面。
- 检查小窝与桌面的模型切换同步、选择持久化、名字与计数保留，以及高清坐姿下的散步限制。

## 打包与本地预览

用户提供的高清 PNG 是应用使用的嵌入资源，和仅用于研究的 `qa/references/` 图片不同。`qa/references/` 不进入便携包；应用所需高清素材随 EXE 嵌入，运行时不另行下载。便携 ZIP 的文件清单仍只有程序和使用说明。

`docs/images/corgi.png` 应更新为当前程序实际显示的高清柯基画面。本轮只构建本地程序与便携包，未上传 GitHub Release。
