小白 · 西高地桌面宠物 v{{VERSION}}，Windows 便携版本。

- 全屏应用时可自动隐藏小白，托盘菜单支持手动隐藏和找回。
- 将桌面鼠标区域收紧到小狗轮廓，并减少睡眠状态动画更新以降低后台负担。
- 小窝可自定义名字，摸摸和喂食次数会保存到本地设置。
- 修复非数字大小设置可能影响启动的问题，并补充配置与输入边界检查。

- 程序生成的立体西高地模型与连续毛发。
- 按真实西高地照片重塑双耳：缩短尖端、加宽并埋入耳根，调整内耳露出比例与边缘毛，让轮廓更接近自然的立耳三角形。
- 摸摸、喂食、睡觉、自由散步和立体网球互动。
- 可拖动透明桌面窗口、缩放、置顶、多显示器边界处理与托盘菜单。
- 闭眼闭嘴的伏地睡姿，以及更平稳的玩球动作。
- 小窝支持当前用户的开机自启动，默认关闭；自启动时只显示桌面小狗。
- 桌面点击、右键和拖动直接使用二维输入层，避免对动态三维毛发进行昂贵的鼠标命中检测。
- 快速拖动即使未及时收到中途移动事件，也会在松开时按最终位置完成移动，不再误判为摸摸。
- 新增有大小限制的本地 runtime.log，记录窗口状态、输入、界面长时间停顿和退出原因，便于排查失去响应或消失；不包含在分享包中。
- 自动渲染检查移至屏幕外运行，避免检查窗口被误认为卡住后自行消失的正式宠物。

下载 WestiePet-v{{VERSION}}-windows.zip，解压后双击“小白-西高地桌面宠物.exe”。需要 Windows 10 / 11 和启用了 WPF 的 .NET Framework 4.x。无需安装或管理员权限，请在可写入的普通文件夹中运行。
