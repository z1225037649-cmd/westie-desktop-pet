小白 · 西高地桌面宠物 v{{VERSION}}，Windows 便携版本。

- 程序生成的立体西高地模型与连续毛发。
- 摸摸、喂食、睡觉、自由散步和立体网球互动。
- 可拖动透明桌面窗口、缩放、置顶、多显示器边界处理与托盘菜单。
- 闭眼闭嘴的伏地睡姿，以及更平稳的玩球动作。
- 小窝支持当前用户的开机自启动，默认关闭；自启动时只显示桌面小狗。

下载 WestiePet-v{{VERSION}}-windows.zip，解压后双击“小白-西高地桌面宠物.exe”。需要 Windows 10 / 11 和启用了 WPF 的 .NET Framework 4.x。无需安装或管理员权限，请在可写入的普通文件夹中运行。

源码、构建说明、操作方法和效果预览见仓库 README。下载文件的 SHA-256 见随附的 SHA256SUMS.txt。
