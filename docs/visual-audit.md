### V1 · P1 · 眨眼的虹膜外漏在新采样图中消失，但闭合眼睑形成明显圆片

- 旧证据：21:15:12 版本的 `qa/scratch-animation/eye-study.png`，以及 21:14:44 的 `qa/coat-study/details/face-pet.png`，上下眼睑中间出现白色横条，横条上下仍露出黑色虹膜。仅作为修复前记录。
- 新证据：21:18:11.976 的 `qa/scratch-animation/eye-study.png`，Animated / blink 与 Natural / blink 两行，在 19、52、90 三个标注角度中，原有黑色漏出已不可见。**这几个采样的遮挡改善已验证；完整眨眼过程和所有视线方向尚未验收。**
- 新图仍可见：闭合眼睛是两块边缘完整的灰色椭圆，中央一条水平线，像覆盖在白脸上的圆盖。侧面仍能看到圆片外缘。此处的可见色差与独立轮廓是图像事实；“像圆盖”是对观感的描述，根因未在本审查中验证。
- 建议验收目标：眨眼时仍能读到上下眼睑，但圆片边界应融入眼眶；前、三分之四和侧面均不露出虹膜，也不因修复遮挡而出现整圈灰盖。睡眠的闭眼形态与眨眼采用不同表现，不能用睡眠图代替眨眼验收。

### V2 · P2 · 睡眠正脸的眼下和唇缘有零碎灰点/短线

- 证据：`qa/coat-study/details/sleep-face-front.png`，21:14:51.371。闭眼线下方、口鼻两侧附近能见到不连续灰色小点和锯齿状短线，唇缘附近也有少量细碎亮暗点。
- 本图的闭眼线本身简洁，未见明显虹膜，不能与 V1 的旧眨眼漏出混为一项。
- 灰点可能涉及几何、法线、毛根或采样，单张图不能确认原因；建议在最终近景静帧复验，并检查实际显示尺寸是否仍可见。
