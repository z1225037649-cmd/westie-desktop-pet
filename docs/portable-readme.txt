小白 · 西高地桌面宠物 v{{VERSION}}

解压后双击“小白-西高地桌面宠物.exe”。
需要 Windows 10 / 11，以及启用了 WPF 的 .NET Framework 4.x。
无需安装，不需要管理员权限。请放在可以写入文件的普通文件夹内运行。

拖动小狗移动位置，滚轮调整大小，右键打开菜单。托盘可临时隐藏或找回小白。
空格：摸摸；F：喂食；B：玩球；S：睡觉/叫醒；R：切换自由散步（西高地）。
快捷键在宠物窗口获得焦点时生效。
关闭小窝后小狗仍会运行；退出请使用托盘菜单或右键菜单。
在小窝的“宠物模型”下拉框，或右键“宠物模型”子菜单中，可即时切换西高地和柯基。
桌面小狗与小窝预览同步更新；切换时保留名字、互动次数、位置和大小。
程序会在旁边生成“小白.settings.xml”保存模型选择、名字、互动次数、位置和大小等设置。
模型选择在重启后恢复；旧设置缺少模型值，或模型值无法识别时，默认使用西高地。

柯基已采用用户选定的三维模型，制作骨骼和面部变形后渲染为连续透明动画。可呼吸、眨眼、歪头摸摸、张嘴咬食、前爪拨球、伏身趴睡及起身。
食物和球与宠物使用同一套动画相机，球在爪子接触后才滚动。睡觉时保持末帧，叫醒或再次互动时先起身，再接续动作。
柯基朝向切换使用镜像，当前没有完整转身、四足步行或自由散步。散步相关操作在柯基下不可用，切回西高地后保留原散步设置。
高清素材已嵌入程序，运行时无需另外下载图片或模型。
西高地已替换为用户提供的三维模型，保留体型、蓝项圈和高清贴图，增加随身体变形的细毛，并可实时转向、步行和伏低睡觉。
西高地保留自然闭眼、视线跟随、带停顿的待机动作和交互修复。
西高地玩球时先抬起前爪，再拨动网球，球滚动后逐渐停下。

小窝内可勾选“开机自启动”，默认关闭，只对当前 Windows 用户生效。
自启动时只显示桌面小狗。移动程序文件夹后，请重新关闭并开启自启动。
全屏应用时默认暂时隐藏小白；可在小窝设置中关闭此行为。睡觉时动画会降低刷新频率，柯基趴下后保持睡姿。
